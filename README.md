# Intranet-Deca

## Contexto

El Documento Electrónico de Control Administrativo (DECA) es la versión
digital del documento que acredita el transporte público de mercancías por
carretera.

Se presenta mediante un código QR para que la inspección pueda verificar los
datos del servicio: cargador, transportista, origen, destino, mercancía y
matrícula. Es obligatorio para el transporte interior y el cabotaje en España.

## Claves de Cloudflare

Las claves de Cloudflare están externalizadas por seguridad. Se encuentran en
Notion, en [Intranet Deca](https://app.notion.com/p/Intranet-Deca-3f470b1f1778805a9678f39a21bafe9d).
